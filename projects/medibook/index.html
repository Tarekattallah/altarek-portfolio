MediBook — Healthcare Appointment Booking

A web-based healthcare appointment management platform designed to simplify scheduling using the MERN stack.

React Node.js Express.js MongoDB JWT RBAC
Live Demo

Overview

MediBook is a full-stack web application designed to alleviate the common friction points found in healthcare scheduling. It provides a seamless interface for patients to book appointments and for clinic administrators to manage availability.

The Problem

Traditional clinic scheduling often relies on phone calls and manual ledgers, leading to double-bookings, missed appointments, and administrative bloat. A modern, digital approach was required to handle real-time availability and user notifications.

The Solution

Built using the MERN stack (MongoDB, Express.js, React, Node.js), MediBook offers a responsive frontend for users to browse availability and a robust backend REST API to securely process bookings.

Key Features

  • Patient Portal: A user-friendly React frontend allowing patients to register, view schedules, and book open slots.
  • Admin Dashboard: A secure interface for clinic staff to manage daily schedules, approve appointments, and update doctors' availability.
  • RESTful API: A scalable Node.js/Express backend that handles all business logic and CRUD operations securely.
  • Database Integration: MongoDB utilized for flexible document storage, managing complex relationships between patients, doctors, and appointments.

Engineering Challenges

Handling timezone discrepancies and preventing double-bookings required careful date/time manipulation on the backend. The API validates all incoming booking requests against the database in real-time, using transactional constraints to ensure a slot is locked the moment it is selected by a user.

Lessons Learned

Working on MediBook solidified my full-stack integration skills, particularly the communication between a React SPA (Single Page Application) and a secure REST API. It highlighted the importance of handling loading states, error boundaries, and optimistic UI updates on the frontend to provide a smooth user experience even when backend latency occurs.
